# menu/

The Command menu (Kotodama).

| Folder | Files | What they change | Applies |
|---|---|---|---|
| `kotodama/` | `user.toml` | App names, KubaOS's actions and toggles you hide, your own actions, the project folders, quicklinks. Read after KubaOS's `kubaos.toml`, key by key | on save |

`kotodama config` prints the merged settings and where each value came from. The Command
menu's "Settings: Menu" opens this folder in Files.

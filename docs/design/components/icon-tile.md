# IconTile

## `IconTile`

Rust `icon_tile::icon_tile`; QML `IconTile`. Its mockup page is the source of truth: Molecules, IconTile, in `design/mockups/`.

What an app or a sender looks like in a row: a symbol or a picture on a tinted square of one size, sm 32 beside one line (a 20 icon), md 40 beside a title over a subtitle (24, `icon.two_line`) and lg 48 over a `headline` name, the one thing a view is about (32, the headline's: a network or a device being connected), at the control radius, on `surface_container_highest`, which reads on a list, a card and a selected row alike (`error` for a critical notification). Its symbol is `on_surface_variant`, or `primary` on the tiles of a list's rows in use (`accent`: the network or the devices connected). An app's icon is measured once when it loads, and the result is kept for that icon: the box of the pixels it draws (alpha above `icon_tile.ink`), so the margin its theme leaves round it drops away, and whether that box is a plate. It is a plate when the box is square (short side at least `icon_tile.square`, 0.95, of the long one) and its pixels with alpha above `icon_tile.opaque` (a half) cover at least `icon_tile.plate`, 85%, of it. A rounded square covers about 95% and a disc 78.5%, so the line falls in a clear gap. A plate fills the whole tile, centred, and the tile's `radius.control` corners cut it, so the two make one edge. Anything else is a shape, fitted `space.s4` inside the tile, centred: 24 in sm, 32 in md, 40 in lg. Either is kept whole (contain), never cropped and never stretched, its box snapped to whole device pixels and centred as the symbol is, the odd pixel after. A photo (a notification's image) covers the tile. The symbol shows until the picture has loaded and stays when there is none, so every row reads the same size whatever each vendor drew. A count can take the symbol's place (a `NotificationPopup` standing for several from one app): the number in `body_strong`, whose 20 line fills the box the sm tile's 20 symbol does, in the symbol's colour, centred as the symbol is, 99+ past 99. *Not built yet: neither library draws a count on a tile.* The Command menu's rows, the notifications', a `ListRow`'s with `tile` and the control center's connection form. It is a mark, not a control: the row it sits in lights, and the tile doesn't change with it.

The iced and QML builds measure each icon once when it loads and cache the result per icon, with the thresholds from the `icon_tile` tokens. *Not built yet:* both still draw an app's icon inset at the symbol's size.
